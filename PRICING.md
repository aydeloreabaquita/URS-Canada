# Proposed Package Pricing

All amounts are preliminary and in CAD.

## Package 1 — Website + Customer Intake
**CAD $1,500–$1,900**

Includes:
- public website modernization;
- red / black / white branded interface;
- mobile-responsive design;
- emergency-response calls-to-action;
- service request form;
- customer contact capture;
- secure production form handling;
- basic admin login;
- customer inquiry dashboard;
- New / Contacted / Scheduled / Closed statuses;
- internal notes;
- basic testing and training.

## Package 2 — Website + Admin Operations
**CAD $2,400–$2,900**

Includes everything in Package 1, plus:
- centralized customer records;
- property/service address records;
- project/claim records;
- staff assignment;
- branch assignment;
- management dashboard;
- up to 6 agreed automations;
- role-based staff access;
- operational reporting.

## Package 3 — Complete Digital Operations System
**CAD $3,400–$4,500**

Includes everything in Packages 1 and 2, plus:
- broader website modernization;
- secure customer portal;
- customer project dashboard;
- approved project-status updates;
- document area/uploads;
- field/technician workflow;
- expanded management dashboard;
- expanded workflow automation;
- documentation;
- team training;
- launch support.

## Optional Launch-Partner Credit

A **CAD $100 credit** may be applied after successful project delivery if URS voluntarily:

- provides an honest review of the completed work; and
- grants permission for the completed website/system to be featured in the developer's professional portfolio.

The review does not need to be positive.

## External costs

Hosting, domain fees, third-party subscriptions, email/SMS services, paid APIs and other external services are separate unless explicitly included in the final agreement.
