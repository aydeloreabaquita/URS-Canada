# Production Roadmap

The demo proves the customer-to-admin workflow. A production implementation would be completed in phases.

## Phase 1 — Secure Website Intake
- Backend form endpoint
- Database-backed requests
- Spam protection
- Privacy/consent logging
- Branch routing
- Emergency notifications

## Phase 2 — Secure Admin Portal
- Server-side authentication
- Password hashing or SSO
- Role-based permissions
- User management
- Audit history

## Phase 3 — Operations Workflow
- Customer records
- Property records
- Claim/job records
- Branch assignment
- Project manager assignment
- Technician assignment
- Status workflow
- Photos/documents
- Activity history

## Phase 4 — Customer Portal
- Customer accounts
- Project status
- Approved updates
- Important dates
- Documents
- Customer uploads
- Requests/messages

## Phase 5 — Integrations
After reviewing a future client's systems, integrate with appropriate:
- email;
- calendar;
- accounting;
- estimating/restoration software;
- document storage;
- SMS;
- CRM;
- reporting tools.

The goal should be to complement existing systems where possible rather than unnecessarily replace them.
